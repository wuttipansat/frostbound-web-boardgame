# Item pictures

Every item card shows an **empty dashed frame** (in the colour of its type) until a picture exists.
To add one, drop a PNG into `public/items/` named after the item id — no code change needed:
the game checks each file once and swaps the frame for the picture.

- Size: **128 × 128 px** (64 × 64 also works; it is shown pixelated), transparent background.
- Name: exactly the id below, e.g. `public/items/canned-beans.png`.
- Step 8 items (gadgets, consumables, materials, new weapons and armor) are listed at the end of the table.
